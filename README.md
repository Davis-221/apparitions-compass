# Marian Pilgrim

Create a mobile app for Marian Apparitions across the world ranging from those Apparitions approved by the Catholic Church to those in the process. Based on the video shared create a mobile app with each and every Apparition mentioned in the Video.

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://apparitions-compass.lovable.app
